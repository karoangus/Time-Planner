# 📚 Time Planner (پلنر مطالعه)

یک وب اپلیکیشن سبک و زیبا برای مدیریت ساعات مطالعه، به زبان فارسی.

## ✨ ویژگی‌ها

- ➕ **افزودن درس** با نام دلخواه
- ⏱ **ثبت ساعات مطالعه** برای هر درس (با پشتیبانی از عدد اعشاری مثل ۱.۵)
- 📝 **ثبت جداگانه ساعات تست** برای هر درس، با پشتیبانی از ساعت اعشاری
- 📊 **نمایش آمار کلی** (تعداد دروس، مجموع ساعات مطالعه و تست، تاریخ امروز)
- 📄 **خروجی PDF شیک و مرتب** شامل جدول دروس و ساعات مطالعه و تست
- 🔄 **دکمه اتمام هفته** — ساعات مطالعه و تست همه دروس را صفر می‌کند ولی دروس باقی می‌مانند
- 🗑 **حذف درس** (با تأیید)
- 💾 **ذخیره‌سازی محلی** — داده‌ها در localStorage مرورگر ذخیره می‌شوند
- 📱 **طراحی واکنش‌گرا** (RWD) — مناسب موبایل و دسکتاپ
- 🎨 **رابط کاربری مدرن** با گرادینت و افکت شیشه‌ای (Glassmorphism)
- 🇮🇷 **راست‌چین** با فونت فارسی Vazirmatn

## 🚀 استفاده

فقط کافیست فایل `index.html` را در مرورگر باز کنید، یا با یک سرور استاتیک سرو کنید:

```bash
# با پایتون
python3 -m http.server 8000

# یا با npx
npx serve .
```

## 🛠 تکنولوژی‌ها

- HTML, CSS (Tailwind CDN), JavaScript خالص (Vanilla)
- [jsPDF](https://github.com/parallax/jsPDF) + [html2canvas](https://html2canvas.hertzen.com/) برای خروجی PDF
- [فونت وزیرمتن](https://fonts.google.com/specimen/Vazirmatn) برای نمایش فارسی
- `localStorage` برای ذخیره‌سازی داده‌ها

## ⚠️ نکته

پس از کلیک روی «اتمام هفته» ساعات و تعداد ثبت‌های مطالعه و تست صفر می‌شوند ولی خود دروس باقی می‌مانند. قبل از اتمام هفته، PDF گزارش هفتگی را دریافت کنید.
