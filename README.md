# 📚 Time Planner (پلنر مطالعه)

![نسخه](https://img.shields.io/badge/version-1.0.0-indigo) ![offline ready](https://img.shields.io/badge/offline-ready-brightgreen)

یک وب اپلیکیشن سبک و زیبا برای مدیریت ساعات مطالعه، به زبان فارسی — **کاملاً آفلاین**؛ مناسب استفاده حتی در حالت «اینترنت ملی».

## ✨ ویژگی‌ها

- ➕ **افزودن درس** با نام دلخواه
- ⏱ **ثبت ساعات مطالعه** برای هر درس با دکمه‌های افزایش و کاهش ۱۵ دقیقه‌ای
- 📝 **ثبت جداگانه ساعات تست** برای هر درس با گام‌های ۱۵ دقیقه‌ای
- 📊 **نمایش آمار کلی** (تعداد دروس، مجموع ساعات مطالعه و تست، تاریخ امروز)
- 📄 **خروجی PDF شیک و مرتب** شامل جدول دروس و ساعات مطالعه و تست
- 🔄 **دکمه اتمام هفته** — ساعات مطالعه و تست همه دروس را صفر می‌کند ولی دروس باقی می‌مانند
- 🗑 **حذف درس** (با تأیید)
- 💾 **ذخیره‌سازی محلی** — داده‌ها در localStorage مرورگر ذخیره می‌شوند
- 📴 **آفلاین واقعی (PWA)** — Service Worker نسخه‌بندی‌شده؛ یک‌بار آنلاین باز کنید و برای همیشه از روی همان دستگاه اجرا کنید (حتی بدون اینترنت بین‌الملل)
- 🛡 **ذخیرهٔ دائمی** — با `navigator.storage.persist()` از پاک‌سازی خودکار برنامه توسط مرورگر جلوگیری می‌شود و وضعیتش در «تنظیمات» نمایش داده می‌شود
- ✅ **دکمهٔ «ذخیرهٔ آفلاین» و «تست آفلاین»** — پرکردن کش و بررسی سلامت نسخهٔ آفلاین با یک لمس
- 💾 **پشتیبان‌گیری / بازگردانی JSON** — خروجی و ورودی کامل داده‌ها؛ تنها راه انتقال امن داده بین آدرس‌های مختلف برنامه
- ⚡ **حالت سبک** — خاموش‌کردن بلورهای پس‌زمینه روی گوشی‌های ضعیف (`html.lp-perf`)
- 📱 **قابل نصب** — روی اندروید، آیفون و دسکتاپ؛ همراه آیکون و صفحهٔ آفلاین fallback
- 📱 **طراحی واکنش‌گرا** (RWD) — مناسب موبایل و دسکتاپ
- 🎨 **رابط کاربری مدرن** با گرادینت و افکت شیشه‌ای (Glassmorphism)
- 🇮🇷 **راست‌چین** با فونت فارسی Vazirmatn

زمان‌ها با قالب ساعت:دقیقه نمایش داده می‌شوند (مثلاً ۲:۱۵). داده‌های قبلی حفظ می‌شوند؛ زمان‌های اعشاری قدیمی به نزدیک‌ترین دقیقه نمایش داده می‌شوند و ممکن است مضرب ۱۵ دقیقه نباشند.

## 🚀 استفاده

برای نصب و قابلیت آفلاین، برنامه را با یک سرور استاتیک روی HTTPS (یا localhost برای آزمایش) باز کنید؛ باز کردن مستقیم فایل برای نصب و سرویس‌ورکر کافی نیست:

```bash
# با پایتون
python3 -m http.server 8000

# یا با npm
npm run serve
```

در مرورگرهای پشتیبانی‌شده دکمهٔ «📲 نصب روی گوشی» یا گزینهٔ نصب در منوی مرورگر را بزنید. در آیفون و آیپد، صفحه را در Safari باز کنید و از منوی اشتراک‌گذاری گزینهٔ **Add to Home Screen** را انتخاب کنید. اولین بار باید آنلاین باشید تا فایل‌ها ذخیره شوند؛ بعد از آن برنامه بدون اینترنت هم باز می‌شود.

> ✅ **پیشنهاد:** بعد از اولین اجرای آنلاین، به پایین صفحه (کارت «⚙️ تنظیمات») بروید و دکمهٔ **«✅ ذخیره آفلاین روی این دستگاه»** را بزنید و سپس با دکمهٔ **«🧪 تست آفلاین»** مطمئن شوید همه‌چیز ذخیره شده است.

## 📴 آفلاین و اینترنت ملی — صادقانه

اگر اینترنت ایران روی حالت ملی برود، فقط سایت‌ها و اپ‌هایی که روی سرورهای داخل ایران میزبانی می‌شوند (معمولاً همراه با دامنهٔ ‎.ir) قابل‌دسترسی‌اند. **github.io و هر هاست خارجی دیگر در آن شرایط فیلتر است.**

- **«ایرانی کردن دامنه» از داخل این برنامه ممکن نیست.** ثبت دامنهٔ ‎.ir (از طریق ایرنیک و ثبت‌کنندگان ایرانی) و هاست/سرور داخل ایران فقط با حساب‌ها و پرداخت ایرانیِ خودتان ممکن است؛ این کار از طرف برنامه انجام نمی‌شود.
- **اما برای اجرای همین برنامه به هیچ دامنه‌ای نیاز نیست:** یک‌بار آنلاین بازش کنید، «✅ ذخیره آفلاین» را بزنید، نصب کنید و همیشه از آیکون اجرا کنید — حتی در اوج نت ملی بدون یک بایت اینترنت بین‌الملل باز می‌شود و کار می‌کند.
- داده‌ها روی **خودِ همان دستگاه** ذخیره می‌شود؛ حذف داده‌های مرورگر، نصب نکردن از آیکون، یا تغییر آدرس برنامه (origin) باعث جدا شدن داده‌ها می‌شود. برای انتقال یا محافظت، از **💾 پشتیبان‌گیری JSON** استفاده کنید.
- اگر به‌هرحال خواستید روی زیرساخت ایرانی میزبانی کنید، کل برنامه فایل‌های استاتیک است؛ کافی است مخزن را روی یک هاست استاتیک داخل ایران (مثلاً Liara یا هر هاست ایرانی دیگر) با دامنهٔ ‎.ir خودتان آپلود کنید. (این کار نیاز به حساب و دامنهٔ خودتان دارد و از داخل برنامه انجام شدنی نیست.)

## 💾 پشتیبان‌گیری و انتقال داده

در کارت «⚙️ تنظیمات»:

- **«💾 دریافت فایل پشتیبان»** — تمام داده‌ها را به صورت یک فایل JSON دانلود می‌کند.
- **«📥 بازگردانی از فایل پشتیبان»** — فایل JSON را خوانده و جایگزین داده‌های فعلی همین مرورگر می‌کند (با تأیید شما).

نکته: چون localStorage به هر آدرس (origin) جداگانه تعلق دارد، داده‌های github.io با داده‌های هاست ایرانی یا localhost یکی نیستند؛ همین فایل پشتیبان تنها پل انتقال داده است.

## 🛠 تکنولوژی‌ها

- HTML, CSS (Tailwind تولیدشده به‌صورت محلی + `css/offline.css` خالص)، JavaScript خالص (Vanilla)
- [jsPDF](https://github.com/parallax/jsPDF) + [html2canvas](https://html2canvas.hertzen.com/) برای خروجی PDF
- [فونت وزیرمتن](https://github.com/rastikerdar/vazirmatn) برای نمایش فارسی (محلی)
- `localStorage` برای ذخیره‌سازی داده‌ها + Cache Storage برای آفلاین
- Service Worker با استراتژی network-first (صفحه/CSS/JS/JSON) و cache-first (تصویر و فونت)

## ⚠️ نکته

پس از کلیک روی «اتمام هفته» ساعات مطالعه و تست صفر می‌شوند ولی خود دروس باقی می‌مانند. قبل از اتمام هفته، PDF گزارش هفتگی را دریافت کنید.

## 🔧 بالا بردن نسخه (برای توسعه‌دهنده)

هنگام انتشار، همهٔ این‌ها باید **هم‌زمان** عوض شوند (تست `npm test` این را اجبار می‌کند):

1. `package.json` → `version`
2. `package-lock.json` → `version` (و ریشهٔ `packages[""].version`)
3. `app-version.json` → `version` (و در صورت تمایل `cache`)
4. `service-worker.js` → `LP_APP_VERSION` (CACHE_NAME خودکار از آن ساخته می‌شود)
5. `js/offline.js` → `LP_APP_VERSION`
6. `index.html` → کوئری `?v=` در `css/offline.css`، `js/offline.js` و `pwa.js`
7. `offline.html` → شمارهٔ نسخهٔ نمایش‌داده‌شده
8. این فایل → تاریخچهٔ نسخه‌ها و badge بالای صفحه

## بازسازی CSS

پس از تغییر کلاس‌های Tailwind در `index.html`، فایل CSS محلی را با Tailwind نسخه ۳.۴.۱۷ بازسازی کنید. برای نمونه:

```bash
printf '@tailwind base;\n@tailwind components;\n@tailwind utilities;\n' > /tmp/time-planner-tailwind.css
npx --yes tailwindcss@3.4.17 -i /tmp/time-planner-tailwind.css -o assets/app.css --content './index.html' --minify
```

نکته: استایل‌های بخش آفلاین/تنظیمات عمداً در `css/offline.css` و به صورت CSS خالص نوشته شده‌اند تا بدون بازسازی Tailwind هم کار کنند.
